# 금감원 정보기술부문 사고보고 — 규정 요약 (스킬 1 근거)

출처: 전자금융감독규정 제37조의5 · **동 시행세칙 제7조의4** · 별지 제2호서식. (법제처 국가법령정보 MCP로 원문 확인, 2026.4.20 개정본)

## 보고 대상 (제7조의4 ①)
1. 정보처리시스템·통신회선 장애로 — **가.** 지연·중단 **30분 이상**, 또는 **나.** 지연·중단 **10분 이상 + 가입자 1만명 이상**
2. 전산자료·프로그램의 조작 및 오류 사고
3. 전자적 침해행위로 시스템 사고 / 이용자 금전피해 통지
4. 전자금융거래법 제9조1항 사고

## 보고 제외 (제7조의4 ②)
1. ①1 중 **1개 영업점에 국한**된 중단·지연
2. ①1 중 **단순 정보제공 공개 웹서버 등** 금융서비스 무관 장애
3. 법9조1항1·3호 사고 중 **사고금액 100만원 미만**

## 보고 단계·시한 (제7조의4 ③④)
| 단계 | 시한·방법 |
|---|---|
| 최초보고 | 인지·발견 후 **24시간 이내**, **EFARS**로 (부득이 시 서면·팩스·유선 후 즉시 EFARS 재보고) |
| 중간보고 | 보완 필요 시 즉시. 조치완료까지 2개월 이상 → 인지일로부터 2개월 이내 + 종결까지 매 6개월 (2개월 미만 종결 시 생략 가능) |
| 종결보고 | 원인·조치·재발방지(+배상책임 시 배상조치) 완료, 정상업무 복귀 시 (최초보고 시 조치완료면 생략 가능) |
| 일괄보고(예외) | 법9조1항1호 사고 중 사고금액 3억원 미만 → 매월분 익월 15일까지 별첨2 |

## 제출 메커니즘 (중요 — 스킬 경계)
- **EFARS = 금감원 운영 웹 기반 보고 시스템.** 회사가 지정한 **비상연락 담당자**가 접속해 보고서를 등록.
- **공개 API 없음 / 보안격리망** → 스킬은 자동 제출 불가. 스킬은 **EFARS 입력용 필드 블록 + 첨부용 보고서**를 만들고, 제출은 사람이 한다.

## 별지 제2호서식 전체 구조 (원본 PDF 대조, <개정 2025.2.5>)

서식은 **① 표지(공문) + ② 별첨1(사고내용) + ③ 별첨2(일괄보고서)** 3파트로 구성된다. PDF 생성 기능(`generate_fss_pdf.py`)은 이 구조를 그대로 재현한다.

### ① 표지 (공문)
- 우상단 박스: **작성자(직위)**, **전화번호**
- 제목: **정보기술부문 및 전자금융 사고보고서**
- **문서번호** / **수신**(예: 금융감독원장) / **참조** / **제목**: 정보기술부문 및 전자금융 사고보고
- 본문: "**전자금융감독규정 제37조의5**에 따라 붙임과 같이 사고를 보고합니다."
- 붙임: 사고내용 1부. 끝.
- 명의: **○○금융회사 사장 (인)** → 카카오페이증권은 **「카카오페이증권 주식회사   대표이사   (인)」** (법인명은 `company.json`의 `legal_name`, 서명 직위는 `representative_title`).

### ② 별첨1 — 정보기술부문 및 전자금융 사고내용
- **보고형태**: □최초 □중간 □종결
- **사고유형** (3분류 중 택1, 하위 체크박스):
  - **침해사고**: `1.공격 대상`(내부망/DMZ/기타/미상) · `2.공격 방법`(악성코드·웹쉘·랜섬웨어 / 서비스거부(DDoS) / 보안취약점 해킹 / 무단접속·조작 / **공급망 보안침해(연계기관 해킹)** / 기타 / 미상) · `3.공격에 따른 피해`(시스템·서비스 중단 / **정보유출** / 중요정보 조작 / 금전적 손실 / 기타 / 미상)
  - **전산장애사고**: 업무처리 프로그램 오류(로직/데이터 오류) / 시스템 장애(서버·네트워크·스토리지·보안장비, OS·DBMS·미들웨어·WAS 등) / 시설·설비 장애(전원차단·통신회선 훼손) / **외부요인으로 인한 장애(클라우드·통신·제휴업체 등)** / 미정
  - **전자금융사기사고**: 피싱·파밍(인터넷/모바일/텔레뱅킹) / 전자상거래·매체 위변조 / 신종 전자금융사기 / 원인미정
- **최초 인지**: □금융회사 □고객(민원인) □기타
- **사고인지일시 / 사고발생일시 / 사고종료일시**
- **피해자 정보 및 피해금액**: 성명 · 생년월일 · 피해금액
- **배상금액 / 배상인원수**
- **사고금액 / 사고 영향 이용자수**
- **사고발생 업무(시스템)명**
- **사고내용(현상 및 결과)** / **사고원인(변경시점 및 사유 등)**
- **파급영향(영향받은 금융회사 등)** / (외부요인 시) **사고 원인 회사명**
- **처리결과** / **대책**
- **<선택 입력사항> 공격자 정보**(침해사고): 공격유형(DDoS/파밍악성코드/C&C서버/기타) · 공격방법 · 공격자IP · 공격자MAC · Domain정보 · 상세내용

### ③ 별첨2 — 일괄보고서 (전자금융사기사고 전용)
법9조1항1호 사고금액 3억원 미만 사기사고를 **매월분 익월 15일까지 일괄보고**할 때 사용.
- 보고연월 · 보고형태(□최초) · 사고유형(전자금융사기사고) · **전체피해금액 / 전체피해인원수**
- 피해자별: 피해자 정보(성명·생년월일·피해금액) · 세부 사고유형(피싱·파밍 등) · 최초인지 · 인지/발생/종료일시 · 배상금액 · 사고내용 · 사고원인 · 파급영향 · 처리결과 · 대책

> 카카오페이증권 특성: 외부 브로커(DriveWealth 등) 연계 장애 = **사고유형 '외부요인으로 인한 장애'**, 파급영향의 **'사고 원인 회사명'**에 해당 업체 명시.
